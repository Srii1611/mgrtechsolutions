# SEO Layer Implementation Plan (Phase 7)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the site machine-readable — a sitemap covering all 148 routes, a robots file, and structured data — closing the gap where a studio that sells local SEO shipped none of it.

**Architecture:** Pure schema-builder functions in `src/lib/schema.ts` under test, injected as `<script type="application/ld+json">` by the routes that own each schema type. `app/sitemap.ts` and `app/robots.ts` use Next's file conventions. Blog metadata gains a derived short title so search results are not truncated.

**Tech Stack:** Next.js 16.3 App Router, TypeScript, Vitest.

**Spec:** `docs/superpowers/specs/2026-08-25-mgrtech-site-rebuild-design.md`

## Why this phase exists

Ten of the site's own blog articles instruct readers to add `LocalBusiness` schema. The site has none. A prospect who reads the blog and views source finds the studio didn't take its own advice. That is a credibility problem as much as a technical one.

## Global Constraints

- **Phone `774-460-1116`** via `SITE`; `508-306-1802` nowhere.
- **No page may assert a headcount of one.**
- **The street address is NEVER published** — not in visible copy, and not in JSON-LD. `LocalBusiness` declares a **service area**, not a `streetAddress`. `33 Annetta Rd` is residential.
- **Do not fabricate data to satisfy a schema.** If a required-ish field has no honest value (publish dates, review counts, aggregate ratings), omit the field. Inventing `aggregateRating` or a `datePublished` is both a Google policy violation and dishonest.
- **Prices stay placeholders.** Do NOT emit `Offer`/`priceSpecification` schema with `$X,XXX` — omit pricing schema entirely until real figures exist.
- No hex in components; `accent-ink` on cream, `accent` on forest.
- Server Components by default; `'use client'` only on leaves.
- `prefers-reduced-motion` disables transforms and transitions.

## Existing interfaces

- `@/data/site` → `SITE` (`name, legalName, domain, url, email, phone, phoneHref, location, tagline`)
- `@/lib/blog` (server-only) → `getAllPosts`, `getPost`, `getPostsByCategory`, `getRelatedPosts`, `slugifyHeading`, types `Post` / `BlogHeading`
- `@/data/blog-categories` → `CATEGORIES`, `CATEGORY_BY_SLUG`
- `@/data/faq` → `FAQ_GROUPS` (typed `FaqGroup[]`, groups of `{q, a}`), `FAQ_HERO`, `FAQ`
- `@/data/home` → `WORK` (seven projects, 3 live / 4 demo)
- Root layout already sets `metadataBase`, a title `default` + `template`, a description, and basic `openGraph`
- All nine static routes and both blog dynamic routes already set their own `metadata` / `generateMetadata` with `alternates.canonical`
- Gates: `npm test` (76), `npx tsc --noEmit`, `npm run verify:copy`, `npm run build`

**Route inventory** — 148 total: `/`, `/about`, `/blog`, `/contact`, `/faq`, `/pricing`, `/process`, `/services`, `/work` (9 static) + 132 posts + 6 categories + `/api/lead` (excluded from sitemap).

### Task 1: Schema builders

**Files:**
- Create: `src/lib/schema.ts`, `src/lib/schema.test.ts`, `src/components/JsonLd.tsx`

**Interfaces:**
- Produces:
  - `buildLocalBusiness(): object`
  - `buildWebSite(): object`
  - `buildArticle(post: { slug; title; excerpt; category; datePublished?: string }): object`
  - `buildBreadcrumbs(items: { name: string; url: string }[]): object`
  - `buildFaqPage(items: { q: string; a: string }[]): object`
  - `<JsonLd data={...} />` — a Server Component

**`buildLocalBusiness` — the important one, and the one most likely to get the address wrong.**
It must emit `@type: 'ProfessionalService'` (a `LocalBusiness` subtype), `name` from `SITE.legalName`, `url`, `telephone` from `SITE.phone`, `email`, `description`, `image`/`logo` pointing at `/brand/logo-mark.png`, and — critically — an `areaServed` listing the MetroWest towns plus `address` limited to `addressLocality: 'Ashland'`, `addressRegion: 'MA'`, `addressCountry: 'US'`. **No `streetAddress` key at all.** A service-area business declares where it works, not where the owner lives.

**`buildArticle`** — `@type: 'Article'`, `headline` (the post title, capped at 110 chars per Google's limit), `description` from the excerpt, `author` and `publisher` as the organisation, `mainEntityOfPage` the canonical URL, `articleSection` the category. **`datePublished` is emitted ONLY if supplied.** Never invent one.

**`buildFaqPage`** — `@type: 'FAQPage'` with `mainEntity` of `Question`/`Answer` pairs.

`JsonLd` renders:

```tsx
export default function JsonLd({ data }: { data: object }) {
  return (
    <script
      type="application/ld+json"
      dangerouslySetInnerHTML={{ __html: JSON.stringify(data) }}
    />
  );
}
```

`dangerouslySetInnerHTML` is correct and required here — JSON-LD must be raw script content. The data is ours, not user input. **Escape `<` as `<`** in the serialized output so a `</script>` sequence inside any string cannot break out of the tag.

### Task 2: Blog SEO metadata

**Files:**
- Modify: `src/lib/blog.ts`, `src/lib/blog.test.ts`, `app/blog/[slug]/page.tsx`

**Interfaces:**
- `Post` gains `seoTitle: string` and `datePublished?: string`

**The problem:** 99 of 132 post titles exceed 70 characters; the longest is 108. With the layout's ` — MGRTECH Solutions` suffix appended, rendered `<title>` tags run 70–128 characters against Google's ~60-character display budget. Descriptions come from a 280-character excerpt against a ~155-character budget. Both get truncated mid-word in results.

**RULING — derive a short title, do not hand-write 132 of them.**
Most of these titles are `Short Hook: Longer Explanatory Subtitle`. So:
1. If the title is ≤ 60 characters, `seoTitle` is the title.
2. Else, if it contains `: ` and the segment before the colon is between 15 and 60 characters, use that segment.
3. Else, truncate at the last word boundary at or before 57 characters and append `…`.

**RULING — blog posts drop the site-name suffix.** Use `title: { absolute: seoTitle }` in `generateMetadata` so the ` — MGRTECH Solutions` template does not eat the budget. The `og:title` may keep the full title.

**RULING — descriptions get their own cap.** Add `metaDescription` derived from the excerpt, truncated at a word boundary at or before 155 characters. The on-page `excerpt` stays 280 for card display.

**RULING — no fabricated dates.** Add optional `datePublished` frontmatter. No article has one, so none is emitted today. Phase 9 may stamp the launch date across all 132 — that is honest, because they genuinely publish then. Do not invent per-article dates.
