## Global Constraints

- **Phone `774-460-1116`** via `SITE`; `508-306-1802` nowhere.
- **No page may assert a headcount of one.** First person singular is fine where Srii speaks to the reader; claims about company size are not.
- **Prices stay `$X,XXX` / `$XXX+` / `$XX/MO+` placeholders.** The owner supplies real figures before launch. Do not invent numbers.
- **Do not link a placeholder Calendly URL.**
- **No hex values in components** — tokens only, `currentColor` in SVG.
- **`accent-ink` is the only accent-family token legible as text on cream** (5.0:1). `accent` is for text on forest (10.4:1). Never `accent`/`accent-strong` as text on cream.
- `.on-dark` on dark sections.
- **`prefers-reduced-motion: reduce` disables transforms and transitions entirely.**
- Mobile-first; semantic HTML; **one `<h1>` per page and no orphaned `<h3>`** — every page needs a correct heading outline, `sr-only` `<h2>` where a visible one would clutter.
- Server Components by default; `'use client'` only on leaves.
- **Motion is Framer Motion + Lenis only.** The prior build used GSAP in several of these components — drop it. No scroll pinning, no typewriter effects, no WebGL.
- **Do not add a second lead form.** Pages that need a conversion point link to `/contact` or use the phone. `ReviewForm` accepts `showHeader={false}` if a page genuinely warrants embedding it — but prefer a link.
