# Homepage Implementation Plan (Phase 4)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the 13-section homepage — the site's primary sales asset — as server-rendered Server Components, with every word of copy carried over from the prior build except the solo-studio claims, which are rewritten.

**Architecture:** All copy lives in `src/data/home.ts` as typed objects, per the spec's convention. Section components render from that data and are Server Components by default; only the three that need state or events are `'use client'` leaves. `app/page.tsx` composes them inside a shared `Band` wrapper that alternates forest/cream and prints a labelled hairline divider.

**Tech Stack:** Next.js 16.3 App Router, React 19, TypeScript, Tailwind v4, Framer Motion, Lenis.

**Spec:** `docs/superpowers/specs/2026-08-25-mgrtech-site-rebuild-design.md`

## A note on this plan's form

Earlier plans in this project carried complete TSX for every component. This one carries **complete, verbatim copy** (Task 1) and **precise structural specs plus one fully-worked reference section** (Task 2) rather than full source for all thirteen. The copy is the part that must not drift — it is the client's marketing language and it encodes the positioning rules. The markup is repetitive variation on a pattern the reference section establishes. Implementers follow that pattern; the review catches drift.

## Global Constraints

- **Phone is `774-460-1116`** (`tel:+17744601116`), always via `SITE.phoneHref` / `SITE.phone`. The string `508-306-1802` must appear nowhere.
- **No section may assert a headcount of one.** Sell "one accountable point of contact and no handoffs," never company size. First-person singular is fine where Srii speaks to the reader ("I build", "I'll say so"); claims about company size are not.
- **Any form on this page MUST post to `/api/lead`** and may only show a success state on HTTP 200. Reusing the real form is mandatory — see Task 5.
- **Pricing is `$X,XXX` placeholder** and stays that way until the owner supplies real numbers. Mark it visibly as starting-at pricing; do not invent figures.
- **Do not link a placeholder Calendly URL.** The phone number is the only primary CTA.
- **No hex values in components** — tokens only.
- **`accent-ink` is the only accent-family token legible as text on cream** (5.0:1). `accent` is for text on forest (10.4:1). `accent-strong` is for hover backgrounds on cream. Never use `accent` or `accent-strong` as text on cream.
- Apply `.on-dark` to forest sections so the focus ring stays visible.
- **`prefers-reduced-motion: reduce` disables transforms and transitions entirely.**
- **Mobile-first.** 375px first.
- Semantic HTML; meaningful `alt`; decorative images get `alt=""` + `aria-hidden`; accessible names; WCAG AA.
- **Server Components by default**; `'use client'` only on leaves.
- **Motion is Framer Motion + Lenis only.** No GSAP, no three.js. The prior build used GSAP ScrollTrigger pinning and a WebGL hero — both are dropped, see Tasks 2 and 3.
